# 更好用的 boss 直聘

结合你的目标职位与简历，AI 快速生成量身定制的打招呼与回复话术，帮你打动 HR、拿到更多回复，提升求职成功率——浏览过的职位自动记录，沟通中的 HR 自动建档，不喜欢的公司一键屏蔽，求职过程有条不紊。**最终是否发送，始终由你掌控。**

## 为什么做这个

求职时最耗神的不是面试，而是 HR 沟通：消息发出去常常石沉大海，HR 可能根本没看到；想跟进时又记不清谁是谁、上次聊到哪。这个扩展把沟通收拢到侧边栏——每位 HR 的档案与最后沟通时间一目了然，太久没动静就适时跟进一下，让你的消息重新被 HR 看到，提升回复概率；点开过的职位自动记录、话术 AI 生成、不想投的公司一键屏蔽，其余琐事一并交给它。

## 功能特性

### 🤖 AI 求职助手

- **多厂商支持**：内置 11 家厂商预设（智谱 GLM、DeepSeek、Kimi、通义千问、MiniMax、腾讯混元、火山方舟、小米 MiMo、OpenAI、Anthropic、OpenCode Go），一键启用；也支持自定义任意 OpenAI 兼容 / Anthropic 接口
- **四种生成场景**：打招呼、聊天回复、跟进消息、请教反馈，均结合职位、HR 档案与简历生成
- **思考模式**：默认 / 关闭 / 低 / 中 / 高五档，按厂商能力自由切换
- **用量统计**：AI 调用日志完整记录，调试页展示平均 TPM 与总 Token 消耗

### 📋 职位自动记录

- **浏览即入库**：点开过的职位自动记录职位名、薪资、公司、规模、行业、描述、标签、地址等全字段
- **规模标签**：职位列表卡片直接显示公司规模，扫一眼就知道是不是外包
- **公司信息卡**：职位列表页工作时，工作台实时显示当前选中职位的公司名、公司人数、行业与 HR 活跃状态

### 💬 HR 沟通管理

- **自动建档**：聊天页自动同步 HR 档案（姓名、头衔、公司、最后消息），未沟通时长一目了然
- **Pass 排除**：工作台或记录页一键标记，聊天页对应会话盖上「已 Pass」遮罩，不再打扰
- **等你回复**：超过一天未回复的会话自动标记提醒

### 🚫 屏蔽公司

- **名单管理**：设置页标签式增删，支持逗号分隔批量粘贴、一键导入常见外包公司模板、复制备份与清空
- **列表遮罩**：职位列表页命中的公司卡片盖上「已屏蔽」遮罩，显示命中词与公司原名，误伤一眼可辨
- **一键屏蔽**：在公司信息卡上直接点「屏蔽该公司」，当前公司立即加入名单
- **误伤提醒**：包含匹配的短词可能误伤，设置页黄条提示用全称规避

### 🗂️ 记录与数据

- **多维记录页**：职位时间流、公司聚合、HR 档案、地区聚合四个维度，虚拟滚动表格支持排序，聊天记录在 HR 档案内展开查看
- **存储占用**：设置页显示浏览器对本扩展的存储估算，数据量一目了然

### 🔧 调试工具

- **页面探测**：聊天页 / 职位列表页 / 职位详情页三处悬浮探测按钮，规避 BOSS 反调试，无需 DevTools 即可查看运行日志
- **AI 日志**：按来源分类查看打招呼、回复、跟进、请教反馈的完整调用记录
- **页面采集日志**：实时查看当前页面的采集与同步日志，可复制导出
- **Bug 反馈**：调试页底部直达语雀问题记录文档

## 安装

### 方式一：下载安装（推荐普通用户）

访问 **[下载页](https://518luck.github.io/hi-job/)**，下载最新版 zip 解压后，按页面教程在 `chrome://extensions/` 加载即可。

### 方式二：本地构建（开发者）

> ⚠️ 本地构建使用「加载已解压的扩展程序」安装；需要选择**整个构建目录**（内含 `manifest.json`），不是里面的某个文件。

1. 克隆项目并安装依赖：`pnpm install`
2. 启动开发构建：`pnpm run dev`（产物输出到 `.output/chrome-mv3-dev/`）
3. 打开 Chrome，地址栏输入 `chrome://extensions/`
4. 开启右上角「开发者模式」
5. 点击「加载已解压的扩展程序」，选择 `.output/chrome-mv3-dev/` 文件夹
6. 工具栏出现扩展图标，点开侧边栏即可使用

> ⚠️ 加载的目录**别删、别挪**，扩展需要持续读取它；代码改动后到 `chrome://extensions/` 点刷新按钮生效。

## 快速上手

1. **配置 AI**：侧边栏「AI 厂商」页，点击内置厂商芯片（如 DeepSeek）预填配置，填入你的 API Key，点「拉取模型列表」获取真实模型；或自定义任意 OpenAI 兼容接口
2. **选择模型**：工作台选择厂商、模型与思考模式
3. **上传简历**：工作台「简历」上传 `.md` 或 `.docx`（自动转 Markdown），AI 生成时会参考简历内容
4. **开始使用**：打开 BOSS直聘 职位列表页浏览职位、在聊天页使用 AI 生成打招呼与回复
5. **屏蔽公司**：设置页「屏蔽公司」添加名单，或在工作台公司信息卡一键屏蔽；职位列表页自动盖遮罩

## 开发

```bash
pnpm install      # 安装依赖
pnpm run dev      # 开发模式（默认 Chrome；-b firefox 切 Firefox）
pnpm run build    # 生产构建
pnpm run typecheck  # 类型检查
pnpm run lint     # 代码检查
pnpm run fix      # 自动修复与格式化
```

发版（在 main 上执行：bump 版本 + commit + 打 tag + 推送，tag 推送自动触发 release 流水线发布 GitHub Release）：

```bash
pnpm release:patch  # 0.1.0 → 0.1.1（修 bug）
pnpm release:minor  # 0.1.0 → 0.2.0（加功能）
pnpm release:major  # 0.1.0 → 1.0.0（大改）
```

## 隐私与合规

- **数据本地存储**：职位记录、HR 档案、聊天消息、简历、屏蔽名单全部保存在浏览器本地（IndexedDB），不上传任何服务器；删除扩展即彻底清除
- **API Key 本地保存**：厂商密钥只存浏览器本地，不会出现在日志中
- **AI 调用的边界**：使用 AI 生成功能时，相关职位信息与简历内容会发送给你**自己配置**的 AI 厂商（浏览器直连，密钥由你持有），用于生成打招呼、回复等文本
- **运行边界**：扩展只在 `*.zhipin.com` 页面运行，不触碰其他网站
- **不绕过平台规则**：不绕过登录、验证码、风控或付费权限，不伪装自动化痕迹；所有沟通动作由你手动发起
